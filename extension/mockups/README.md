# Mockups

Files here are **not shipped** — `.vscodeignore` keeps them out of the VSIX.
They exist to generate the Marketplace screenshots.

## Screenshot pipeline

```bash
bash extension/mockups/screenshot.sh
```

Renders `screenshot.html` and `screenshot-sidebar.html` in headless Chrome and
writes the PNGs used by `extension/README.md`. `sidebar-styles.gen.js` is
generated by that script (and gitignored) — don't edit it by hand.

Keep these in sync with the real UI whenever the panel or sidebar changes
visually, or the Marketplace screenshots drift from what users actually see.

## Removed: design proposals

Seven `proposal-*.html` files (variants a–g) explored panel layouts before the
composable preset UI settled in June 2026. They were superseded by the shipped
design, referenced by nothing, and accounted for roughly 340 KB — enough to
make GitHub report this TypeScript project as ~48% HTML.

They're in git history if a past variant is ever worth revisiting:

```bash
git log --diff-filter=D --oneline -- 'extension/mockups/proposal-*.html'
git show <commit>^:extension/mockups/proposal-g-complete.html
```
